## 一、在线 RL
================================================================================

### RLT
  bash requirements/install.sh embodied --model openpi --env frankasim
  source .venv/bin/activate
  Docker: source switch_env openpi

额外：
  Stage 1 需 π₀.₅ base 权重 huggingface.co/lerobot/pi05_base
  Semi-Taks-T1 assets 已位于 assets/Semi_Taks_T1

### Sim-Real Co-Training
  bash requirements/install.sh embodied --model openpi --env frankasim
  source .venv/bin/activate

额外：
  使用 Semi-Taks-T1 仿真和对应真机 LeRobot 数据

## 六、安装方式
================================================================================

### 方式一：UV 本地环境
  git clone https://github.com/RLinf/RLinf.git
  cd RLinf
  bash requirements/install.sh <target> --model <model> --env <env>
  source .venv/bin/activate

  target: embodied | agentic | docs
  查看全部选项：bash requirements/install.sh --help

  可选 flag：
    --use-mirror          国内加速
    --venv <dir>          指定 venv 目录
    --python 3.10         behavior/d4rl 需要 3.10，默认 3.11.14
    --torch <version>     指定 PyTorch wheel
    --platform amd|ascend|musa   非 NVIDIA 显卡

  国内加速 clone：git clone https://gh-proxy.com/github.com/RLinf/RLinf.git

### 方式二：Docker
  当前仓库没有同时包含 OpenPI 和 FrankaSim 的预构建镜像。
  本批 Semi-Taks-T1 配方优先使用 UV 本地环境；Docker 需基于 docker/Dockerfile 自行组合构建。

### 验证
  python -c "import rlinf; print(rlinf.__file__)"
  ray --version
