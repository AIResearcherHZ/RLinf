================================================================================

文档：rst_source/start/installation.html

## 一、在线 RL
================================================================================

### RLT
Semi-Taks-T1 / FrankaSim 版：
  bash requirements/install.sh embodied --model openpi --env frankasim
  source .venv/bin/activate
  Docker: source switch_env openpi

ManiSkill 版（对应 maniskill_rlt_stage2_*_mlp.yaml）：
  bash requirements/install.sh embodied --model openpi --env maniskill_libero
  source .venv/bin/activate
  Docker: source switch_env openpi

额外：
  Stage 1 需 π₀.₅ base 权重 huggingface.co/lerobot/pi05_base
  Semi-Taks-T1 assets 已位于 assets/Semi_Taks_T1
  ManiSkill assets 见文末"通用额外依赖"

### Sim-Real Co-Training
Semi-Taks-T1 / FrankaSim 版：
  bash requirements/install.sh embodied --model openpi --env frankasim
  source .venv/bin/activate
  Docker: source switch_env openpi

ManiSkill 数字孪生版（对应 maniskill_ppo_co_training_openpi_pi05.yaml）：
  bash requirements/install.sh embodied --model openpi --env maniskill_libero
  source .venv/bin/activate
  Docker: source switch_env openpi

额外：
  使用 Semi-Taks-T1 仿真和对应真机 LeRobot 数据
  ManiSkill 数字孪生版使用 maniskill_pick_and_place_digital_twin 环境

## 六、安装方式
================================================================================

### 方式一：UV 本地环境
  git clone https://github.com/RLinf/RLinf.git
  cd RLinf
  bash requirements/install.sh <target> --model <model> --env <env>
  source .venv/bin/activate

  target: embodied | agentic | docs
  查看全部选项：bash requirements/install.sh --help

  可选 flag：
    --use-mirror          国内加速
    --venv <dir>          指定 venv 目录
    --python 3.10         behavior/d4rl 需要 3.10，默认 3.11.14
    --torch <version>     指定 PyTorch wheel
    --platform amd|ascend|musa   非 NVIDIA 显卡

  env 名注意：
    ManiSkill 环境在 install.sh 里注册为 maniskill_libero（与 LIBERO 共用安装分支），
    不是 maniskill；写 --env maniskill 会报 "unsupported env"。
    SUPPORTED_ENVS 完整列表见 requirements/install.sh 顶部。

  国内加速 clone：git clone https://gh-proxy.com/github.com/RLinf/RLinf.git

### 方式二：Docker
  当前仓库没有同时包含 OpenPI 和 FrankaSim 的预构建镜像。
  本批 Semi-Taks-T1 配方优先使用 UV 本地环境；Docker 需基于 docker/Dockerfile 自行组合构建。

### 验证
  python -c "import rlinf; print(rlinf.__file__)"
  ray --version

## 通用额外依赖
================================================================================

国内 HF 加速：
  export HF_ENDPOINT=https://hf-mirror.com

ManiSkill assets（ManiSkill 版方法需要，install.sh --env maniskill_libero 已自动下载）：
  # install.sh 已调用 download_assets.sh --assets maniskill，无需手动执行
  # 若自动下载失败，手动补下：
  bash requirements/embodied/download_assets.sh --assets maniskill
  # 或按 RLinf 仓库内的 assets 集合下载（含 ManiSkill 官方 source assets）：
  cd rlinf/envs/maniskill
  hf download --repo-type dataset RLinf/maniskill_assets --local-dir ./assets
  # MS_ASSET_DIR 默认在 <repo>/.maniskill，由 download_assets.sh 设置
