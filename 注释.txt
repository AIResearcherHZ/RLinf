## 一、在线 RL
================================================================================

### RLT（RL Token）
页面：rst_source/examples/embodied/rlt.html
配置（Semi-Taks-T1）：
  Stage 1  examples/sft/config/semi_taks_t1_rlt_stage1_sft_openpi_pi05.yaml
  Stage 2  examples/embodiment/config/semi_taks_t1_rlt_stage2_ac_mlp.yaml
           examples/embodiment/config/semi_taks_t1_rlt_stage2_td3_mlp.yaml
Stage 1  lerobot 演示 SFT π₀.₅ + RLT token transformer → 表示 z_rl
Stage 2  冻结 feature model，只训 MLP actor-critic
         状态={z_rl, proprio, ref_chunk}，off-policy + transition replay
reward  Semi-Taks-T1 使用末端-方块距离、抬升高度和 success bonus 的 dense reward
         chunk 内 gamma 折扣进 TD target
关键    loss_type=rlt_ac/rlt_td3, rollout.collect_transitions=True
         rollout.rlt_feature_model.model_path → Stage 1 checkpoint


### Sim-Real Co-Training
页面：rst_source/examples/embodied/co_training.html
配置（Semi-Taks-T1）：examples/embodiment/config/semi_taks_t1_ppo_co_training_openpi_pi05.yaml
流程  Semi-Taks-T1 MuJoCo 在线 PPO + 真机 lerobot SFT loss 联合
      L_Total = L_RL + beta * L_SFT
数据  50 条真机 LeRobot 轨迹（RLCo-Example-Real-Data），actor.sft_data_path
关键  enable_sft_co_train=True, sft_loss_weight=0.2

## 二、离线 RL
================================================================================

### STEAM
页面：rst_source/examples/embodied/steam.html
配置（Semi-Taks-T1）：
  examples/offline_rl/config/semi_taks_t1_steam_value_model_sft.yaml
  examples/offline_rl/config/semi_taks_t1_steam_compute_advantages.yaml
  examples/offline_rl/config/semi_taks_t1_steam_cfg_rl_openpi.yaml
三阶段  Value Model SFT (SigLIP+Gemma3) → worst-of-N advantage → CFG Training (π₀.₅)
特点  value 信号=专家演示时序进度，无需 reward 标注
模型  π₀.₅ + SigLIP-so400m + Gemma3-270M


### RECAP
页面：rst_source/examples/embodied/recap.html
配置（Semi-Taks-T1）：
  examples/offline_rl/config/semi_taks_t1_recap_compute_returns.yaml
  examples/offline_rl/config/semi_taks_t1_recap_value_model_sft.yaml
  examples/offline_rl/config/semi_taks_t1_recap_compute_advantages.yaml
  examples/offline_rl/config/semi_taks_t1_cfg_rl_openpi.yaml
四阶段  Compute Returns → Value Model SFT → Compute Advantages → CFG Training
特点  value 信号=回归 discounted return（需 reward），与 STEAM 共享 CFG 阶段
数据  sft（全成功）+ rollout（含失败）两类 lerobot 数据集
