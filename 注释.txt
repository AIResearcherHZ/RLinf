## 数据采集

### 真机遥操作

```bash
bash examples/embodiment/collect_data.sh realworld_collect_data
```

可选配置：

```text

examples/embodiment/config/realworld_collect_data_gello.yaml
examples/embodiment/config/realworld_collect_data_zed_robotiq.yaml
```

### 清除旧仿真数据

```bash
rm -rf /home/xhz/.cache/huggingface/lerobot/semi_taks_t1_put_cube
```

### 仿真自动采集

```bash
PYTHONPATH=/home/xhz/RLinf \
python toolkits/lerobot/collect_semi_taks_t1_lerobot.py \
  --repo-id semi_taks_t1_put_cube \
  --num-episodes 100 \
  --max-attempts 1000 \
  --max-steps 100 \
  --seed 0 \
  --fps 50 \
  --control-mode heuristic \
  --viewer
```

### VR 遥操作采集

先启动 VR 数据发送端，再执行：

```bash
PYTHONPATH=/home/xhz/RLinf \
python toolkits/lerobot/collect_semi_taks_t1_lerobot.py \
  --repo-id semi_taks_t1_put_cube \
  --num-episodes 100 \
  --max-attempts 1000 \
  --max-steps 100 \
  --seed 0 \
  --fps 50 \
  --control-mode vr \
  --operator-height 1.83 \
  --taks-sdk-path /home/xhz/taks-controller-web/backend/libs/SDK \
  --vr-ip 0.0.0.0 \
  --vr-port 7000 \
  --viewer
```

```bash
ls -lah /home/xhz/.cache/huggingface/lerobot/semi_taks_t1_put_cube
```

`--viewer` 下不要设置 `MUJOCO_GL=egl`。仅成功回合写入数据集。
