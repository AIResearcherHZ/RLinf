================================================================================
FrankaSim / Semi-Taks-T1：SAC 前训练 -> RLPD 后训练
================================================================================

通用环境
--------------------------------------------------------------------------------

cd /home/xhz/RLinf

# 首次安装
bash requirements/install.sh embodied --model mlp --env frankasim

source .venv/bin/activate
export REPO_PATH=/home/xhz/RLinf
export EMBODIED_PATH=$REPO_PATH/examples/embodiment
export MUJOCO_GL=egl
export PYOPENGL_PLATFORM=egl
export RESNET_PATH=$REPO_PATH/assets/RLinf-ResNet10-pretrained

ray start --head --num-gpus=1


一、FrankaSim
================================================================================

模型：assets/frankasim_xmls/arena.xml

SAC 前训练：

python examples/embodiment/train_async.py \
  --config-path $EMBODIED_PATH/config \
  --config-name frankasim_sac_cnn_async \
  actor.model.model_path=$RESNET_PATH \
  rollout.model.model_path=$RESNET_PATH

RLPD 后训练，在上面命令末尾追加：

  algorithm.demo_buffer.enable_cache=true \
  algorithm.demo_buffer.cache_size=5000 \
  algorithm.demo_buffer.min_buffer_size=1 \
  algorithm.demo_buffer.sample_window_size=5000 \
  algorithm.demo_buffer.load_path=/absolute/path/to/frankasim_demos \
  algorithm.demo_buffer.auto_save=false

FrankaSim 视频，在训练命令末尾追加：

  env.eval.video_cfg.save_video=True \
  env.eval.video_cfg.video_base_dir=$REPO_PATH/logs/frankasim_video/eval

TensorBoard：tensorboard --logdir $REPO_PATH/logs --port 6006


二、Semi-Taks-T1
================================================================================

模型：assets/Semi_Taks_T1/pickcube.xml
约束：腰部、左臂和左夹爪固定，只控制右臂和右夹爪。
接口：4 维动作（右手 xyz 增量、夹爪开合），7 维状态，前视和腕部双相机。


准备变量
--------------------------------------------------------------------------------

export T1_RESNET_PATH=$RESNET_PATH
export T1_PRETRAIN_LOG=$REPO_PATH/logs/semi_taks_t1_pretrain
export T1_PRETRAIN_BUFFER=$T1_PRETRAIN_LOG/replay_buffer
export T1_RLPD_LOG=$REPO_PATH/logs/semi_taks_t1_rlpd

训练前验证
--------------------------------------------------------------------------------

pytest -q tests/unit_tests/envs/test_semi_taks_t1_pickcube.py

python -c "import gym, rlinf.envs.frankasim; e=gym.make('SemiTaksT1PickCubeVision-v0', image_obs=False); o,_=e.reset(seed=0); print(o['states'].shape, e.step([0,0,0,-1])[1]); e.close()"


SAC 前训练
--------------------------------------------------------------------------------

python examples/embodiment/train_async.py \
  --config-path $EMBODIED_PATH/config \
  --config-name semi_taks_t1_sac_cnn_async

输出：
  checkpoint：$T1_PRETRAIN_LOG/checkpoints/global_step_<N>/
  buffer：$T1_PRETRAIN_BUFFER/rank_0/
  日志：tensorboard --logdir $T1_PRETRAIN_LOG --port 6006


RLPD 后训练
--------------------------------------------------------------------------------

export T1_PRETRAIN_CKPT=$T1_PRETRAIN_LOG/checkpoints/global_step_<N>
export T1_DEMO_BUFFER=$T1_PRETRAIN_BUFFER/rank_0

test -d "$T1_PRETRAIN_CKPT/actor"
test -f "$T1_DEMO_BUFFER/metadata.json"
test -f "$T1_DEMO_BUFFER/trajectory_index.json"

python examples/embodiment/train_async.py \
  --config-path $EMBODIED_PATH/config \
  --config-name semi_taks_t1_rlpd_cnn_async

RLPD 从前训练 checkpoint 恢复，并按 50% 在线数据、50% 先验数据训练。
使用人工示教时，将 T1_DEMO_BUFFER 改为对应的 rank_0 buffer 目录。


评估和视频
--------------------------------------------------------------------------------

python examples/embodiment/train_async.py \
  --config-path $EMBODIED_PATH/config \
  --config-name semi_taks_t1_rlpd_cnn_async \
  runner.only_eval=True \
  runner.resume_dir=$T1_PRETRAIN_CKPT \
  env.eval.video_cfg.save_video=True \
  env.eval.video_cfg.video_base_dir=$REPO_PATH/logs/semi_taks_t1_video/eval


停止：ray stop

排错：
  - T1_PRETRAIN_CKPT 必须指向 global_step_<N>，不能指向 actor 子目录。
  - T1_DEMO_BUFFER 必须指向含 metadata.json 的 rank_0 目录。
  - RLPD 等待时，检查在线 replay 是否达到 min_buffer_size=5。
